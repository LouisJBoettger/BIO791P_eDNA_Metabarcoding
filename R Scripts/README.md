This subsection contains the two R scripts used to analyse all data.

To properly use both scripts you must use them in the same RStudio Project with a shared environment as objects created in one will be used in the other.

BIO791P_Main_Script.R contains primarily analysis of bioacoustics, camera traps and heavy metals - with some eDNA combined in towards the end of the script.

BIO791P_VSEARCH_Analysis.R contains the bulk of eDNA analysis and function, from loading and cleaning VSEARCH output to analysis.
This script does contain some analyses of other methods too, combined with eDNA metabarcoding.
